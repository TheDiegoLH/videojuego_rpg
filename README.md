# videojuego
Este proyecto es un sistema de personajes para un videojuego de rol por turnos, desarrollado en Python. Incluye un menú interactivo que permite crear personajes, verlos, simular batallas y consultar estadísticas.
Cómo descargar el proyecto
Ve al repositorio en GitHub.

Haz clic en el botón verde Code.

Selecciona la opción Download ZIP.

Una vez descargado, descomprime el archivo ZIP en tu computadora.

Abre la carpeta resultante en tu editor (por ejemplo, Visual Studio Code).
Cómo iniciar el programa
Abre una terminal en la carpeta raíz del proyecto (videojuego_RPG).

En Windows: clic derecho → Abrir en terminal.

En VS Code: usa la terminal integrada.

Ejecuta el programa con: main.py
Verás el menú principal en pantalla:
===== MENÚ PRINCIPAL =====
1. Crear personaje
2. Ver personajes
3. Simular batalla
4. Ver estadísticas
5. Salir
Uso del menú
Crear personaje: te pedirá tipo (Guerrero, Mago, Arquero, Sanador), nombre y estadísticas.

Ver personajes: muestra todos los personajes creados con su información.

Simular batalla: selecciona personajes aleatoriamente y simula una pelea por turnos.

Ver estadísticas: muestra cuántos personajes hay de cada tipo.

Salir: termina el programa.
